# meldtime

Meld validation gates for time inputs before they hit prod.

**Site:** https://theworker02.github.io/meldtime/

## Install / run

```bash
git clone https://github.com/theworker02/meldtime.git
cd meldtime
node src/cli.js
node --test
```
